# V38: 환경 복구 후 closest-rival 목적함수 비교

기록일: 2026-10-07(한국 시간). [Linux CPU 설치](README.md) 후 `research/aiflow-1.0e/selective-2d`에서 실행한다. Torch 2.5.1+cpu, NumPy 2.1.3, Python 3.12.14를 사용했다.

V37은 환경 연결 단절로 대조군 1,165단계, 후보 1,173단계에서 중단됐다. 두 arm의 저장 상태는 1,152단계였다. 복구 CLI가 첫 겹침 단계 1,153의 전체 기록 불일치를 검출해 로그를 덧붙이기 전에 종료했다. 별도 TRAIN 진단에서 실제 부동소수 차이를 기록했다. 원인은 격리하지 않았으며 단순 직렬화 차이로 취급하지 않는다.

V38은 같은 V37 목적함수를 **두 arm 모두 현재 환경의 cold canonical부터 다시** 학습한다. 기존 57개 파라미터, 4개 encoder layer, 2,400단계, V25 데이터·스케줄, seed·AdamW·계수·64행 CE와 feature 보존을 유지한다. 후보의 gap은 학생이 가장 높은 비정답 logit을 가진 클래스 하나를 선택하며 교사 정답 행 수로 정규화한다. 정규화 분모까지 변경되므로 같은 계수가 같은 gradient 크기를 뜻하지 않는다. TRAIN 기반 계수 재탐색은 없다.

봉인 계획에는 현재 CPU 모델·CPU capability·Torch build도 저장한다. 실행 중 소스나 하드웨어가 바뀌면 검사를 통과하지 못한다. 출력 경로는 아래처럼 새로운 경로를 사용한다.

```bash
experiment=artifacts/hwr_closest_rival_new_v38_run
python scripts/run_hwr_closest_rival_v38.py prepare --output "$experiment"
python scripts/run_hwr_closest_rival_v38.py train --output "$experiment" --arm v33_control &
control_pid=$!
python scripts/run_hwr_closest_rival_v38.py train --output "$experiment" --arm closest_rival &
challenger_pid=$!
wait "$control_pid"
control_status=$?
wait "$challenger_pid"
challenger_status=$?
test "$control_status" -eq 0 && test "$challenger_status" -eq 0
```

두 프로세스의 종료 코드와 두 `completed.json`이 정상인 경우에만 평가한다. 4-core cgroup에서 각 arm은 Torch thread 2개를 사용한다. 전체 학습은 약 40분이다.

```bash
python scripts/run_hwr_closest_rival_v38.py evaluate --output "$experiment"
python scripts/verify_hwr_closest_rival_v38.py --output "$experiment"
python scripts/audit_hwr_closest_rival_v38.py --output "$experiment"
```

독립 검증은 4,800개 손실 기록·전체 파라미터 갱신·같은 현재 CPU에서 최종 로짓 비트 재현·라벨 provenance·지표 집계를 요구한다. 과거 V35 대조군과는 가중치·기록·지표 차이를 따로 공개한다. 다른 환경의 비트 일치를 이 실험의 통과 조건으로 삼지 않는다. 원래 V37 strict 검증기와 이전 인증서는 변경하지 않는다.

V35 학습·평가 함수 재사용으로 최종 체크포인트와 비교 JSON은 legacy V35 컨테이너를 사용한다. V38 계획·arm·독립 인증서가 현재 실험을 식별한다. 이미 관찰한 149식은 정답 grouping 제공 HWR 진단이며 untouched acceptance·공식 Expression Rate가 아니다. 소유 라벨·CROHME optimizer 입력은 0이다. 중간 평가와 best epoch 선택은 없다.

원래 V37 로그·저장 상태·실패 증거는 별도 디렉터리에 보존했다. 이 폴더를 성공한 학습 결과로 읽지 않는다. 엄격 복구 CLI는 동일한 수치 경로에서만 진행하며, 이번처럼 수치 차이가 있으면 실패를 남긴다. [V37 및 복구 명령](V37.md)
