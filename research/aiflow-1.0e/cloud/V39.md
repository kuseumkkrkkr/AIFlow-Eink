# V39: 전체 near 후보를 보존하는 오류 행 boost

기록일: 2026-10-07(한국 시간). [Linux CPU 환경](README.md)을 준비한 뒤 `research/aiflow-1.0e/selective-2d`에서 실행한다. 이전 실험과 봉인 소스·인증서를 덮어쓰지 않는다.

V38의 단일 경쟁 후보 조건은 fitted TRAIN 오류를 줄였지만 소유 수식은 회귀했다. V39는 기존 teacher/student Top-5 union·정답 제외·teacher-correct mask·pair 수 분모를 유지한다. **교사가 맞고 학생이 틀린 행의 전체 near-pair gap만 2배**로 보정한다. 학생 argmax 판정은 detached이며 나머지 행은 기존 gap과 같다. CE·64행 feature·alpha/beta·데이터·seed·AdamW·예산은 유지한다. Boost 2는 진단 전에 고정했고 검색하지 않았다.

고정 TRAIN 8배치에서 기존 잔여 6개 margin을 진단했다. gap 국소 방향이 margin을 해치는 경우는 2 → 1이었다. 이 진단은 optimizer나 소유 평가 forward를 사용하지 않는다. 새 필기 일반화의 증거가 아니다.

V38의 검증된 같은 CPU 대조군을 재사용한다. 기존 2,400-step 모델·전체 로그·주기 상태·시작 및 완료 기록을 바이트 그대로 복사한다. 출처 계획·인증서·파일 해시를 V39 계획에 봉인하며 원래 `run_started.json`의 V38 plan SHA와 PID도 보존한다. 새로 실행하는 학습은 **후보의 2,400단계 하나**다. 비교에는 대조군의 기존 2,400개 기록을 포함한다. 두 arm을 새로 학습했다고 부르지 않는다.

```bash
experiment=artifacts/hwr_error_boost_near_new_v39_run
python scripts/run_hwr_error_boost_near_v39.py prepare --output "$experiment"
python scripts/run_hwr_error_boost_near_v39.py train --output "$experiment" --arm error_boost_near
```

후보 정상 종료와 두 `completed.json`을 확인한 경우에만 평가한다. prepare는 CPU·Torch build·Python·NumPy와 V38 출처를 검사한다. 다른 플랫폼에서는 임의로 대조군을 재사용하지 않는다. 후보는 원래 trainer의 Torch thread 2개를 유지한다.

```bash
python scripts/run_hwr_error_boost_near_v39.py evaluate --output "$experiment"
python scripts/verify_hwr_error_boost_near_v39.py --output "$experiment"
python scripts/audit_hwr_error_boost_near_v39.py --output "$experiment"
```

`focus_microscope.jsonl`은 step별 teacher-correct 수, 실제 boost 행의 원본/증강 분할, 기존·실제 gap, pair 수를 기록한다. 독립 검증은 2,400개 focus 기록의 step·범위·손실과 optimizer 기록의 일치 및 1–2배 손실 경계를 검사한다. 최종 로짓은 재로딩 후 같은 CPU에서 비트 일치해야 하며, 재사용 대조군은 V38의 원래 로짓·지표와도 일치해야 한다. canonical 지표는 불변 입력·CPU와 기존 V38 인증서에서 재사용하고 출처를 표시한다. canonical forward를 새로 실행했다고 부르지 않는다.

수정하지 않은 V35 train/evaluate 함수를 재사용하므로 모델·비교 JSON에는 legacy V35 컨테이너가 남는다. V39 계획·arm·독립 인증서가 실험을 식별한다. 149식은 반복 관찰한 정답 grouping 제공 HWR 진단이며 untouched acceptance·공식 Expression Rate가 아니다. owned/CROHME optimizer 행은 0이다. 중간 평가와 best epoch 선택은 하지 않는다.
