# AIFlow 1.0e 문제점 보강 구현 결과

## 결론

- R0 출력 무결성, R1 클래스 지원량 감사, R2 학습·선택·손실 계측, R3 guard 분리를 구현했다.
- 현재 최선 개발 후보는 그대로 원본 획 종단간 Exact **32/95 = 33.68%**다.
- 수정된 문맥 CE 경로는 자기 기준선 **14/95 → 15/95**로 1개 개선했지만 32/95 후보보다 낮다. 제품 후보로 채택하지 않는다.
- 신규 writer 자료, 관계 주석, 봉인 평가 자료가 없으므로 R1 HWR 재학습·R3 관계 head·제품 평가는 `blocked_data`다.
- 공개 업로드와 제품 활성화는 수행하지 않았다.

## R2 수치

R2는 현재 32/95 후보와 다른, 고정된 외부 HWR 기준선 위에서 문맥 학습 변경만 검증한 결과다.

| 경로 | 문자 Top-1 | 정답 grouping 문자식 Exact | 종단간 Exact | 기준선 대비 종단간 개선/회귀 |
|---|---:|---:|---:|---:|
| 외부 HWR 기준선 | 208/387 (53.75%) | 15/95 | 14/95 (14.74%) | - |
| raw context | 221/387 (57.11%) | 16/95 | 15/95 (15.79%) | +1 / 0 |
| writer-disjoint guard | 215/387 (55.56%) | 16/95 | 15/95 (15.79%) | +1 / 0 |

- writer bootstrap 개발 구간: +1.05%p, 95% 구간 **0.00~2.97%p**.
- 이 자료는 이미 소비된 개발 자료다. 독립 정확도나 제품 성능으로 해석하지 않는다.
- 최종 32/95 후보와 동일 조건의 직접 향상 실험이 아니므로 두 점수의 차이를 문맥 모델의 손실로 해석하지 않는다.

## 추가된 검증 경계

- 신규 수집 검증기는 writer·prompt 역할 중복, 봉인 기기 중복, 세션 수, 유형 비율, 획 중복·누락 소유, 시간점 누락, 독립 주석, 상업 권리를 검사한다.
- 추론 위치 결측은 `geometry_missing`으로 예측 산출물에 남긴다.
- guard 보정 writer는 최종 guarded student 학습에서도 제외한다.
- 모든 산출물은 새 디렉터리에 기록했고 기존 결과를 덮어쓰지 않았다.

## 검증

- accuracy 계열 단위 테스트: **29 passed**.
- formula context ranker 테스트: **12 passed**.
- 관련 Python 파일 compile 검사 통과.
- R2 전체 산출물: 입력 95, 문자 387, inner 예측 3,561개, 계보 검증 통과.
- 외부 teacher·네트워크 차단 CPU 추론 통과: 금지 모듈 0, 정답 제거 불변, 반복 완료 동일, 원본 잉크 보존. 실제 기기 검증은 아니다.

## 재개 조건

1. 수집 계약 검증을 통과한 신규 자료 확보.
2. `=`·`8` 우선 slice로 head-only와 last-block 조건만 비교.
3. 검수된 구조 관계 자료 확보 후 9-class 관계 head 비교.
4. 한 구성으로 고정한 뒤 신규 봉인 평가 1회 수행.

현재 단계에서 더 많은 KD 반복이나 평가셋 맞춤 규칙 추가는 정확도 극대화가 아니라 개발셋 과적합 위험을 키우므로 중단한다.
