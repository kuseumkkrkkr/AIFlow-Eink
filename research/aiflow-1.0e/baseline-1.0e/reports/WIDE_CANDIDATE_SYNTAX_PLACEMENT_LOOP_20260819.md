# Top-10 문맥·공식 배치 복원 개선 루프

## 결론

- 기존 신경망 경로는 그대로 둔다. 128점 궤적 HWR, 수식 문맥 임베딩, 공식 배치 결과가 후보를 제안하고 마지막 배치 가드가 문법적으로 유일한 복원안만 확정한다.
- 보조 HWR 후보를 연구용 Top-10으로 넓히자 직접 수집의 수식 후보 상한은 81/95에서 88/95(92.63%)로, CROHME 진단의 후보 상한은 646/984에서 773/984로 증가했다.
- 실제 보수적 확정 결과는 직접 수집 문자 355/387에서 358/387(92.51%), 수식 완전일치 76/95에서 78/95(82.11%)로 증가했다.
- CROHME 반복 진단은 문자 7513/9535에서 7516/9535(78.83%), 수식 완전일치 286/984에서 288/984(29.27%)로 증가했다.
- 두 범위 모두 맞던 문자와 완전일치 수식의 회귀는 0건이다. 다만 개발 자료를 반복 관찰했으므로 상태는 `shadow_runtime_only`이며 제품 기본값은 꺼져 있다.

## 구조

```text
128점 온라인 궤적
  → 기본 372-class HWR Top-5
  → 수식 문맥 임베딩·공식 배치·구문 가드
  → 이중 HWR 숫자 operand 복원
  → 보조 HWR Top-10(연구 후보 회수 전용)
  → 유일한 최소 변경 숫자 구문 복원
  → 최종 문자열과 기존 배치 관계
```

마지막 레이어는 새로운 언어모델이 아니다. 기존 HWR·문맥 신경망이 만든 확률을 읽는 결정 경계다. 식 순서와 배치는 기존 공식 배치 경로가 소유하며, Top-10 캐시의 원래 순서는 사용하지 않는다.

## 확정 조건

다음 조건을 모두 만족해야 한 식에서 최대 두 글자를 바꾼다.

- 현재 열이 이미 유효한 숫자 구문이면 보존한다.
- 현재 열에 숫자가 최소 두 개 있고, 길이는 3~64글자다.
- Top-10 안에서 유효해지는 최소 변경안이 정확히 하나뿐이다.
- 숫자 후보 확률은 해당 글자의 보조 HWR 1순위 확률 대비 1% 이상이어야 한다.
- `=` 복원은 보조 HWR 1순위가 실제로 `=`일 때만 허용한다.
- 단일 영문자는 변수일 수 있으므로 숫자로 바꾸지 않는다.
- 산술 결과는 계산하지 않는다.

후보 합집합 밖 생성, 글자 삽입·삭제·순서 변경, stroke grouping, 공식 배치 관계 변경은 모두 0건이다.

## 후보 회수 감사

| 범위 | Top-5 문자 회수 | Top-10 문자 회수 | Top-5 수식 oracle | Top-10 수식 oracle |
|---|---:|---:|---:|---:|
| 직접 수집 95식 | 368/387 | 376/387 | 81/95 | 88/95 |
| CROHME 984식 | 8922/9535 | 9196/9535 | 646/984 | 773/984 |

직접·CROHME Top-10 생성에서 기존 Top-5 앞부분의 토큰 변경과 확률 차이는 모두 0이었다. 직접 캐시는 폭 메타데이터를 명시해 다시 생성했고 이전 Top-10과도 387행 전체 토큰·확률이 동일했다.

## 실제 변경

직접 수집:

- `aiflow_0140`: `1 + \prime = 2` → `1 + 1 = 2`
- `aiflow_0152`: `6 \times 0 \approx \mathcal{O}` → `6 \times 0 = 0`

CROHME 반복 진단:

- `RIT_2014_204.inkml`: 숫자열 내부 `\mathcal{G}` → `4`
- `RIT_2014_70.inkml`: 덧셈열 내부 `|`, `|` → `1`, `1`

초기 분기에서는 `RIT_2014_98.inkml`의 정답 변수 `b`를 `6`으로 바꾸는 문자 회귀가 1건 발생했다. 이를 근거로 단일 영문 변수 잠금을 추가했다. 최종 분기는 직접 3글자·2식, CROHME 3글자·2식을 개선하고 회귀가 0건이다.

## 남은 한계와 다음 루프

- 직접 수집 95식은 임계값과 실패 분석에 반복 사용된 개발 자료다.
- CROHME는 CC BY-NC 반복 진단이며 상용 제품 검증 자료가 아니다.
- Top-10이어도 직접 7식은 정답 후보가 완전히 빠져 있다. 현재 78식과 oracle 88식 사이의 10식은 후보는 있으나 안전하게 확정할 독립 근거가 없다.
- `x/X`, `x/\chi`, `=/\approx`, `+/\bot`처럼 의미가 달라질 수 있는 동형 기호는 문법만으로 강제하지 않는다.
- 보조 HWR 경로와 Top-10 보관은 추론량·메모리를 늘린다.
- 제품 승격에는 신규 작성자·신규 수식의 untouched 상용 가능 acceptance set에서 문자·수식 비회귀, 후보 합집합 보존, 배치·grouping 불변을 다시 통과해야 한다.
