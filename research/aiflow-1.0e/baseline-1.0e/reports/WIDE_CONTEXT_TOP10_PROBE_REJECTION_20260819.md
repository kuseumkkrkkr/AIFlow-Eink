# Top-10 문맥 인식 문자 재배치 신경망 감사

## 결론

- 고정된 자체 수식 문맥 신경망을 Top-10 HWR 후보 위에 연결했지만 식 정확도가 크게 하락해 기각했다.
- 현재 안전 경로의 직접 수집 성능 `358/387` 문자, `78/95` 식 exact는 유지한다.
- 추론 결과를 런타임 설정에 넣지 않았으며 `runtime_admitted=false`다.
- 이번 루프에서 추가 학습은 수행하지 않았다.

## 시험 구조

```text
128점 온라인 궤적
  -> 372-class HWR와 보조 HWR 후보
  -> 기존 보수적 구문·배치 복원
  -> Top-10 후보 + 기존 식 순서·공간 관계
  -> 고정된 자체 수식 문맥 신경망
  -> 후보 안에서만 문자 재선택
```

문자 삽입·삭제, stroke regrouping, 식 순서 변경, 산술 계산은 허용하지 않았다. 다만 문맥 체크포인트는 Top-5 계약 아래에서 선택됐으므로 Top-10 연결은 후보 폭이 달라진 탐색 실험이다.
