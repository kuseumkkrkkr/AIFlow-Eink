# 공식 배치·문맥 교정 레이어 검증

## 결론

- 런타임 순서: `불변 문자 박스 → 기하 배치 → 기존 r6 문맥 신경망 → fence/infix 재검수 → 식 시퀀스 가드`.
- 시퀀스 가드는 산술 정답을 계산하지 않는다. HWR Top-5 안에서 단순 숫자식 문법이 깨진 경우에만 최대 한 글자를 바꾼다.
- 직접 수집 95식에서 기존 정답식 회귀 없이 식 완전일치가 64.21%에서 72.63%로 상승했다.
- CROHME 고정 외부 검수에서는 2자 개선·0자 회귀였다. 다만 CROHME는 비상업 평가용이며 보수화에도 사용했으므로 독립 상용 합격 세트가 아니다.
- 현재 상태는 `shadow_runtime_only`다. 신규 작성자·신규 식의 untouched 합격 검수 전에는 기본 제품 경로로 승격하지 않는다.

## 레이어 계약

- 입력: 기존 stroke ownership으로 확정된 문자 박스와 문자별 HWR Top-5.
- 배치: 입력 `context.index`를 읽지 않고 박스 기하로 순서·분수·루트·첨자를 추론한다.
- 교정: 단일 문자, 문자 혼합식, 이미 문법적으로 정상인 숫자식은 기본적으로 유지한다.
- 보존: 새 토큰 0, 삭제 0, 그룹 변경 0, Top-5 밖 선택 0.
- 안전장치: 후보 확률비 0.02 미만은 거부하되 세로획 계열에서 `1`로 가는 경우만 예외로 둔다. 비숫자 Top-1 확률이 0.99 이상이면 고정한다.
- 산술식이 틀린 답인지 맞는 답인지는 검사하지 않는다.

## 고정 평가

| 범위 | 기존 | r6 shadow | 변화 |
|---|---:|---:|---:|
| 직접 387자 Top-1 | 87.34% | 89.41% | +2.07%p |
| 직접 95식 완전일치 | 64.21% (61/95) | 72.63% (69/95) | +8.42%p, 회귀 0 |
| legacy47 식 완전일치 | 68.09% (32/47) | 74.47% (35/47) | +3식, 회귀 0 |
| 신규 48식 완전일치 | 60.42% (29/48) | 70.83% (34/48) | +5식, 회귀 0 |
| CROHME 9,535자 Top-1 | 78.84% | 78.86% | 2자 개선, 회귀 0 |
| CROHME 984식 문자 완전일치 | 28.76% | 28.86% | +1식, 회귀 0 |
| CROHME 배치+문자 완전일치 | 12.91% | 12.91% | 변화 없음 |

- 직접 데이터 기하 순서 완전일치: 98.95% (94/95).
- CROHME trace-group 순서 proxy 완전일치: 31.61%. 배치가 현재 전체 식 정확도의 가장 큰 병목이다.
- 직접 데이터의 유일한 순서 실패 `aiflow_0074`는 한 문자 박스에 멀리 떨어진 stroke가 섞였고 정답 `0`도 HWR Top-5에 없어 후단에서 복구할 수 없다.
- ownership이 없는 canonical 고정 10식은 이 레이어의 입력 계약을 만족하지 않아 end-to-end 식 정확도를 아직 산출할 수 없다.

## 기각한 신경 배치 도전자

- 603-parameter 첨자 관계망은 합성 검증 macro F1 92.14%였지만 신규 직접 식에서 false-positive 식 2건이 발생해 기각했다.
- CROHME 관계 F1도 기하 기준선 72.85%보다 낮은 64.19%여서 런타임에 연결하지 않았다.
- 체크포인트는 재현 증거일 뿐이며 `shadow_admitted=false`다.
