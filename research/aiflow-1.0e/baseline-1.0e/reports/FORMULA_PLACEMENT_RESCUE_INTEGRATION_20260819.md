# 통합 공식 배치 복원 레이어

## 결론

- 세 개의 후보 보존형 배치 가드를 하나의 순서 고정 레이어로 통합했다.
- 기존 Top-10 구문 복원 기준에서 직접 수집 문자 Top-1은 `358/387 → 362/387`(93.54%), 식 exact는 `78/95 → 81/95`(85.26%)로 증가했다.
- 직접 수집은 3식 개선·0식 회귀, 4글자 개선·0글자 회귀다.
- CROHME 반복 비상업 진단은 `7516/9535` 문자, `288/984` 식 exact로 모든 단계에서 변경 0건이다.
- 제품 기본값은 변경하지 않았다. 통합 결과는 `shadow_runtime_only`다.

## 고정 실행 순서

```text
기존 372-class HWR·문맥·배치·Top-10 구문 복원
  -> Top-20 후보 회수
  -> 1. 짝 없는 닫는 괄호 피연산자 복원
  -> 2. 숫자 사이 십자 연산자 복원
  -> 3. 이중 직선 1 피연산자 복원
  -> 기존 식 순서·관계 그래프 그대로 출력
```

한 글자를 두 단계가 중복 수정하는 경우는 오류로 중단한다. 이번 평가의 단계별 변경은 직접 수집에서 `1, 1, 2`글자, CROHME에서 `0, 0, 0`글자로 재현됐다.

## 누적 개선

| 단계 | 직접 문자 | 직접 식 exact | 직접 식 개선/회귀 | CROHME 식 exact |
|---|---:|---:|---:|---:|
| 입력 기준 | 358/387 | 78/95 | - | 288/984 |
| 짝 없는 괄호 | 359/387 | 79/95 | 1/0 | 288/984 |
| 십자 연산자 | 360/387 | 80/95 | 1/0 | 288/984 |
| 이중 직선 1 | 362/387 | 81/95 | 1/0 | 288/984 |

복원된 식은 다음 세 개다.

- `1 \bot 5 → 1 + 5`
- `5 \times ) = 5 → 5 \times 1 = 5`
- `1 \div I = / → 1 \div 1 = 1`

산술 결과는 계산하지 않았다. 후보 밖 문자 생성, 글자 삽입·삭제, 순서 변경, stroke regrouping, grouping 변경, 배치 관계 변경은 모두 0건이다.

## 기각한 문맥 경로

- 고정 자체 문맥 신경망의 Top-10 전면 재배치: 직접 식 exact `78/95 → 61/95`, 18식 회귀.
- Top-20 전면 재배치: 직접 식 exact `78/95 → 60/95`, 개선 0식·회귀 18식.
- 낮은 확률 숫자 후보 일괄 허용: 직접 1식은 개선됐지만 CROHME 식 exact `288/984 → 284/984`, 문자 회귀 9건.
- `X→x` 단일 문맥 gate: 직접 1식 개선 가능성이 있었지만 CROHME 문자 개선 1건·회귀 3건.

따라서 현재 문맥 신경망은 후보 제안용으로 남기고, 실제 확정은 구조·후보·궤적 조건이 동시에 성립하는 세 경계만 허용했다.

## 남은 실패 14식

Top-20 식 oracle은 `91/95`이고 현재 exact는 `81/95`다.

- 정답이 Top-20 안에 있지만 자동 확정하지 않은 10식: `aiflow_0004`, `0010`, `0018`, `0020`, `0023`, `0056`, `0058`, `0061`, `0078`, `0146`.
- 정답이 Top-20에도 없는 4식: `aiflow_0046`, `0074`, `0163`, `0164`.

첫 집합에는 `x/X/\chi`, `=/\approx`, 영문자·숫자 동형처럼 실제 의미가 달라지는 경우가 남아 있다. 같은 개발식에 맞춰 규칙을 더 만들면 정확도 숫자는 오르지만 의미 회귀 위험이 커진다. 두 번째 집합은 후단 문맥 레이어만으로 해결할 수 없고 HWR 후보 recall 개선이 필요하다.

## 다음 개선 조건

- 동형 문자 문맥 모델: 새 프로젝트 소유 수식열에 `x/X/\chi`, `=/\approx`, `S/5`, `\beta/8` 양성·음성 라벨을 추가한 뒤 writer/formula-disjoint로 재학습한다.
- HWR 후보 회수: Top-20 밖 4식의 원시 궤적을 클래스 불균형·writer 분리 조건으로 다시 학습한다.
- 상용 acceptance: 이번 95식과 겹치지 않는 새 writer·새 formula로 문자·식 비회귀를 검증한다.
- 더 많은 epoch만 같은 자료에 반복하는 것은 현재 병목의 해법이 아니다.
