# 동형 문자 문맥 재순위화 가설 검증

상태: **문맥 재순위화 연구 후보 지지 / 제품 채택 아님**

## 가설과 제약

- 고정된 128×5 궤적 Transformer와 372-class head는 재학습하지 않았다.
- 기존 Top-5 안에서만 `1·|·/`, `0·O·o`, `x·×` 계열 후보 순서를 바꿨다.
- 새 토큰 생성, 획 ownership 변경, 그룹 변경은 금지했다.
- 외부 임베딩이나 XGBoost를 추가하지 않고, 이미 설치된 scikit-learn의 클래스 균형 로지스틱 후보 재순위화기로 먼저 가설을 검증했다.
- 직접 수집은 3개 writer leave-one-out, CROHME는 5개 formula-disjoint fold를 사용했다. C 값은 각 바깥 fold의 학습식만 사용하는 내부 formula-disjoint 평가에서 선택했다.
- CROHME로 만든 재순위화기는 비상업 연구 진단 전용이며 제품 모델로 사용할 수 없다.

| 문자 | 기존 | 문맥 재순위화 | 전체 |
|---|---:|---:|---:|
| `1` | 3 | 14 | 25 |

직접 수집에는 `|`, `O`, `o` 정답이 없고 writer도 3명뿐이므로 제품 승인 근거로는 부족하다.

후보 확률·순위만 사용하면 전체 정확도가 개선되지 않았지만, 앞뒤 문자 문맥을 넣으면 전체 Top-1이 2.30%p, 동형군 Top-1이 13.17%p 상승했다. 따라서 단순 클래스 prior 보정보다 수식 문맥이 실제 추가 정보를 제공한다는 가설은 지지된다. `/`는 1건 감소했으므로 별도 회귀 gate가 필요하다.

## 결정

- 1차 연구 후보는 **후보 + 앞뒤 문자 문맥** 모델이다.
- 기하 특징은 직접 수집에서 소폭 이득이 있었지만 CROHME 전체·수식 exact에서는 문맥 단독보다 낮아 아직 채택하지 않는다.
- 임베딩 모델은 아직 필요하지 않다. 현재 one-hot 문맥만으로 가설이 확인됐고, 새 writer 및 `|/O/o` 표본이 확보된 뒤 소형 임베딩 Transformer와 동일 split에서 비교한다.
- 다음 제품 gate는 새 writer holdout에서 문자별 비회귀, 특히 `/`, `|`, `O`, `o`, `x`, `\times`를 각각 확인하는 것이다.
