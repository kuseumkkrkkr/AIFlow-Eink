# 미니 임베딩 신경망 재순위화 가설 검증

상태: **고정 372-head 대비 부분 지지 / 기존 one-hot 문맥 모델 대체 기각 / 제품 채택 아님**

## 검증 가설

외부 임베딩 모델 전체를 붙이지 않고 아래 신경망만 Top-5 뒤에 추가했다.

```text
후보 토큰 ─┐
앞 토큰 ───┼─ 공유 8차원 임베딩 ─┐
뒤 토큰 ───┘                      ├─ 32-unit GELU MLP ─ 후보 점수
확률·순위·역할·식 내 위치 ────────┘
```

- fold별 파라미터: 3,009~4,697개
- 외부 사전학습: 없음
- 기존 128×5 궤적 Transformer와 372-class head: 고정
- 출력 정책: 동일 동형군의 기존 Top-5만 재정렬
- 토큰 생성, 획 ownership 변경, grouping 변경: 금지

## 누수 방지

- 직접 수집: 3개 writer leave-one-out
- CROHME: 5개 formula-disjoint fold, 비상업 연구 진단 전용
- seed: 17, 31, 47
- epoch와 변경 margin: 바깥 fold의 학습식 내부 formula-disjoint validation에서만 선택
- 모델 선택 후 바깥 학습식 전체로 재학습하고 held writer/formula를 한 번 평가
- 세 seed 다수결을 최종 비교값으로 사용하고 동률이면 기존 Top-1을 보존

## 결정

- **신경망이 문맥을 학습할 수 있다는 가설:** 지지
- **미니 임베딩이 현재 one-hot 문맥 모델을 대체한다는 가설:** 기각
- 현재 1차 연구 후보는 기존 one-hot 문맥 로지스틱 재순위화기로 유지한다.
- 미니 임베딩은 데이터가 더 쌓이기 전에는 복잡도 대비 이득이 없다.
- 재검토 조건은 새 writer와 `|/O/o/x/\times`의 충분한 직접 수집 holdout 확보다.
- CROHME에서 학습된 미니 모델은 비상업 연구용이며 제품에 사용할 수 없다.
