# 통합 공식 배치 복원 레이어

기존 Top-10 구문 복원 뒤에 세 가지 보수적 Top-20 배치 가드를 고정 순서로 합친 shadow 런타임이다. 직접 수집 개발 성능은 문자 `362/387`, 식 exact `81/95`이며 기준 대비 3식 개선·0식 회귀다. CROHME 반복 비상업 진단에서는 세 단계 모두 변경 0건이다.

`formula_placement_rescue_runtime_config.json`은 shadow CLI 재생용이다. 제품 기본값 승격은 새 프로젝트 소유 writer/formula acceptance 전까지 금지한다.
