# Noncommercial evaluation boundary

CROHME, MathWriting, and any source with a noncommercial or research-only term remain outside all 1.0 product-training manifests. They may be used only for frozen research regression evaluation when the source terms permit it.

## CROHME2019 local evaluation copy (2026-08-12)

- Source: Kaggle `ntcuong2103/crohme2019`, CC BY-NC 4.0.
- Location: local-only `crohme2019/`, ignored by Git and never copied into a
  product-training folder.
- The downloaded valid split contains 986 InkML files. One exact duplicate
  formula (`501_em_5.inkml`) is excluded from metrics, leaving 985 formulas.
- Raw InkML metadata may contain writer demographics. Evaluation code reads only
  trace coordinates and truth annotations; it never emits that metadata.
